Sauvegarde automatique sur GitHub (dépôt privé)
    
1) Crée un dépôt privé avec un fichier README. 2) GitHub → Settings → Developer settings → Fine-grained tokens : accès limité à ce seul dépôt, permission « Contents : Read and write ». 3) Renseigne les champs. Le jeton reste dans ce navigateur. « Synchroniser » envoie les sessions manquantes et récupère celles des autres appareils.
