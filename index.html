  Sauvegarde à long terme
  

  

  
Sauvegarde automatique sur GitHub (dépôt privé)
    
1) Crée un dépôt privé avec un fichier README. 2) GitHub → Settings → Developer settings → Fine-grained tokens : accès limité à ce seul dépôt, permission « Contents : Read and write ». 3) Renseigne les champs. Le jeton reste dans ce navigateur. Les sessions, leurs noms et leurs notes sont envoyés tout seuls dès qu’ils changent, et récupérés sur tes autres appareils.

    

    

    

    

    

    
Le code contient le pseudo, le dépôt et le jeton, chiffrés avec une phrase secrète que tu choisis. Il ne sert à rien sans elle.
